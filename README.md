# Projet Panacée (C)

Initialisation minimale d’un projet en C avec un entrypoint et un Makefile simple.

## Commandes utiles

- `make` : compile le projet
- `make run` : compile puis exécute le binaire
- `make clean` : supprime les fichiers de build
- `make fclean` : supprime les fichiers de build + le binaire
- `make re` : rebuild complet (`fclean` puis `make`)
